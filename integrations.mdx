## Financial and Payroll Integrations

Connect TimeLog to accounting and payroll systems to automate invoice generation and salary processing.

<Tabs>
  <Tab title="QuickBooks" icon="database">
    Use the native QuickBooks integration to push approved time entries as invoices.

    <CodeGroup tabs="JavaScript,Python">
      ```javascript
      const QuickBooks = require('node-quickbooks');
      const qbo = new QuickBooks(/* init options */);
      
      const timeEntries = await fetchTimeEntries();
      timeEntries.forEach(async (entry) => {
        await qbo.createInvoice({
          CustomerRef: entry.clientId,
          Line: [{ Amount: entry.hours * entry.rate }]
        });
      });
      ```
      ```python
      import quickbooks
      from timelog import fetch_time_entries
      
      client = quickbooks.QuickBooks(/* sandbox=True */)
      entries = fetch_time_entries()
      
      for entry in entries:
          client.create_invoice(
              customer_ref=entry['client_id'],
              line=[{'Amount': entry['hours'] * entry['rate']}]
          )
      ```
    </CodeGroup>
  </Tab>
  <Tab title="Xero" icon="shield">
    Map projects to Xero contacts for seamless billing.
  </Tab>
</Tabs>

## Webhook Setup Guide

Set up webhooks to receive TimeLog events like time entry approvals or invoice status changes.

<Steps>
  <Step title="Create Webhook" icon="plus">
    Navigate to Settings > Integrations > Webhooks and click "New Webhook".
  </Step>
  <Step title="Configure Endpoint" icon="link">
    Enter your endpoint URL, e.g., `https://your-webhook-url.com/timelog`.
    
    Select events: `time_entry.approved`, `invoice.sent`.
  </Step>
  <Step title="Verify Payload" icon="check-circle">
    TimeLog sends a POST request with JSON payload.
    
    <Request tabs="cURL" show-lines="true">
      ```bash
      curl -X POST https://your-webhook-url.com/timelog \
        -H "Content-Type: application/json" \
        -H "TimeLog-Signature: {signature}" \
        -d '{
          "event": "time_entry.approved",
          "data": {
            "id": 12345,
            "hours": 8.5,
            "user_id": 678
          }
        }'
      ```
    </Request>
  </Step>
  <Step title="Handle Signature" icon="shield">
    Verify the `TimeLog-Signature` header using HMAC SHA256 with your secret.
  </Step>
</Steps>

<ResponseField name="event" field-type="string">
  Type of event triggered.
</ResponseField>

<ResponseField name="data" field-type="object">
  Event-specific payload.
</ResponseField>
