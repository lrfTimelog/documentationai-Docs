Connect your systems to TimeLog: read and change projects, time, expenses, customers and more, or extract the
account's data for reporting. This documentation covers TimeLog's three APIs.

## TimeLog's APIs

<Columns cols={3}>
  <Card title="REST API" icon="braces" href="/rest/overview">
    Read and change data with JSON over HTTPS, acting as a TimeLog user. Two versions, v1 and v2.
  </Card>
  <Card title="Transactional API" icon="arrow-left-right" href="/transactional/guides/authentication">
    A SOAP API with one service per area, such as CRM, Project management and Invoicing. Reads and writes.
  </Card>
  <Card title="Reporting API" icon="bar-chart-3" href="/reporting/guides/authentication">
    A read-only SOAP API for extracting the account's data, as full records or short look-up lists.
  </Card>
</Columns>

Not sure which one you need? See [Choose an API](/choose-an-api).
