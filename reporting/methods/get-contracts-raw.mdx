Returns project contracts, optionally for one project or payment model.

| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetContractsRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Filters: projectID, contractModelType. CONTRACT BUDGETS.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="projectID" field-type="integer" required="true">
Project. 0 = no filter.
</ResponseField>

<ResponseField name="contractModelType" field-type="integer" required="true">
Payment model. 0 or negative = all.
</ResponseField>

    <tlp:GetContractsRaw>

## Response

The result is an XML document inside `GetContractsRawResult`: a `tlp:ProjectContracts` root with one `tlp:ProjectContract` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: None.

<ResponseField name="tlp:ProjectContract" field-type="ContractRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="ProjectContract fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Contract ID.** ProjectSubContractID.
</ResponseField>

<ResponseField name="GUID" field-type="string (attribute)">
**Contract GUID.**
</ResponseField>

<ResponseField name="Name" field-type="string">
**Name.** Contract name. Not cleaned of XML-forbidden characters.
</ResponseField>

<ResponseField name="ContractModelType" field-type="integer">
**Contract model.** Payment model.
</ResponseField>

<ResponseField name="ProjectID" field-type="integer">
**Project ID.** The contract's project.
</ResponseField>

</ResponseField>
