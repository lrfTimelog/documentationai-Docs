Extract contract customers.

| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetContractCustomersRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Filters: project, customer, contract and contract status, combined with AND. The contract-status filter applies to the CONTRACT, which is not returned. Uses a 300 s command timeout.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="projectID" field-type="integer" required="true">
The contract's project. 0 = no filter.
</ResponseField>

<ResponseField name="customerID" field-type="integer" required="true">
The contract customer. 0 = no filter.
</ResponseField>

<ResponseField name="projectSubContractID" field-type="integer" required="true">
The contract. 0 = no filter.
</ResponseField>

<ResponseField name="contractStatusID" field-type="integer" required="true">
Use `-1` for no filter.
</ResponseField>

```python
import requests

  <soap:Body>
    <tlp:GetContractCustomersRaw>

      <tlp:contractStatusID>-1</tlp:contractStatusID>
    </tlp:GetContractCustomersRaw>

response = requests.post(
    URL,
    data=envelope.encode("utf-8"),

rows = parse_result(response)  # see "Responses and errors"
```

## Response

The result is an XML document inside `GetContractCustomersRawResult`: a `tlp:ContractCustomers` root with one `tlp:ContractCustomer` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: Customer name, then customer number; order within one customer is not defined.

<ResponseField name="tlp:ContractCustomer" field-type="ContractCustomerRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="ContractCustomer fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Contract customer ID.** ProjectSubContractCustomerID.
</ResponseField>

<ResponseField name="GUID" field-type="string (attribute)">
**Contract customer GUID.**
</ResponseField>

<ResponseField name="ProjectSubContractID" field-type="integer">
**Contract ID.** The project contract.
</ResponseField>

<ResponseField name="SplitType" field-type="integer">
**Split type.** How the contract amount is split between its customers.
</ResponseField>

<ResponseField name="UserDefinedSplitValue" field-type="decimal">
**User-defined split value.** Split value as entered, CONVERT: four decimals. Meaning per SplitType.
</ResponseField>

<ResponseField name="ComputedSplitPercentageRatio" field-type="decimal">
**Computed share ratio.** Recomputed when payments change. CONVERT: rounded to four decimals.
</ResponseField>

<ResponseField name="CustomerID" field-type="integer">
**Customer ID.** The contract customer.
</ResponseField>

<ResponseField name="CustomerName" field-type="string">
**Customer name.** Customer company name.
</ResponseField>

<ResponseField name="CustomerNo" field-type="string">
**Customer number.** Customer number.
</ResponseField>

<ResponseField name="ProjectID" field-type="integer">
**Project ID.** The contract's project.
</ResponseField>

<ResponseField name="ProjectName" field-type="string">
**Project name.** Cleaned of XML-forbidden characters.
</ResponseField>

<ResponseField name="ProjectNo" field-type="string">
**Project number.**
</ResponseField>

</Expandable>
</ResponseField>
