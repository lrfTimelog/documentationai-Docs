| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetContractPaymentsRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Filters: project, contract customer's customer, contract, plus the mandatory date window. Only payments linked to a contract customer are returned; all installment types are included. The contract is filterable but not returned - join via ProjectSubContractCustomerID to GetContractCustomersRaw. CONTRACT AMOUNTS.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="projectID" field-type="integer" required="true">
The payment's project. 0 = no filter.
</ResponseField>

<ResponseField name="customerID" field-type="integer" required="true">
The contract customer's customer. 0 = no filter.
</ResponseField>

<ResponseField name="projectSubContractID" field-type="integer" required="true">
Contract ID. 0 = no filter.
</ResponseField>

<ResponseField name="startDate" field-type="dateTime" required="true">
InvoiceDate >= value. An invalid value -> ASMX fault.
</ResponseField>

<ResponseField name="endDate" field-type="dateTime" required="true">
InvoiceDate &lt;= value. Same typing as startDate - an OMITTED endDate becomes 0001-01-01 and the result is EMPTY.
</ResponseField>

## Response

The result is an XML document inside `GetContractPaymentsRawResult`: a `tlp:ContractPayments` root with one `tlp:ContractPayment` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: InvoiceDate; ties not ordered.

<ResponseField name="tlp:ContractPayment" field-type="ContractPaymentRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.
