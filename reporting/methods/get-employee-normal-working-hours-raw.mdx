description: "Reporting API: Returns the weekday hours of each normal-working-time scheme, once per employee currently assigned to it."

| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetEmployeeNormalWorkingHoursRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Only the CURRENT assignment is reflected - history is in GetEmployeeNormalWorkingTimeHistoriesRaw. status 0 does NOT return inactive employees.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="employeeID" field-type="integer" required="true">
Employee id. 0 = no filter.
</ResponseField>

<ResponseField name="departmentID" field-type="integer" required="true">
Current profile department, exact. 0 = no filter.
</ResponseField>

<ResponseField name="status" field-type="integer" required="true">
As GetWorkingHoursRaw: only > 0 is sent; 1 = active only; 0 / negative = ALL.
</ResponseField>

## Response

The result is an XML document inside `GetEmployeeNormalWorkingHoursRawResult`: a `tlp:EmployeeNormalWorkingTimes` root with one `tlp:EmployeeNormalWorkingTime` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: Employee id only; weekday order within an employee NOT guaranteed.

<ResponseField name="tlp:EmployeeNormalWorkingTime" field-type="EmployeeNormalWorkingTimeRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="EmployeeNormalWorkingTime fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Normal working time ID.** NOT unique in the document.
</ResponseField>

<ResponseField name="Weekday" field-type="integer">
**Weekday.**
</ResponseField>

<ResponseField name="Name" field-type="string">
**Scheme name.**
</ResponseField>

<ResponseField name="WorkingHours" field-type="decimal">
**Hours.**
</ResponseField>

<ResponseField name="EmployeeID" field-type="integer">
**Employee ID.** Assigned employee; omitted for a scheme without users.
</ResponseField>

<ResponseField name="EmployeeFirstName" field-type="string">
**Employee first name.**
</ResponseField>

<ResponseField name="EmployeeLastName" field-type="string">
**Employee last name.**
</ResponseField>
