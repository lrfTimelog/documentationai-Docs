Returns the account's CRM events with status, date, contact and linked opportunity.

| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetEventsRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Filters: event, event type, customer, responsible employee, status and a date range.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="eventID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="eventTypeID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="customerID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="employeeID" field-type="integer" required="true">
Employee in charge of the event. 0 = no filter.
</ResponseField>

<ResponseField name="status" field-type="integer" required="true">
Use `0` for no filter. Event status. Values > 4 are passed through and match nothing.
</ResponseField>

<ResponseField name="startDate" field-type="string">
**Optional.** Send yyyy-MM-dd.
</ResponseField>

<ResponseField name="endDate" field-type="string">
**Optional.** Event date &lt;= value.
</ResponseField>

import requests

## Response

The result is an XML document inside `GetEventsRawResult`: a `tlp:Events` root with one `tlp:Event` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

<ResponseField name="tlp:Event" field-type="EventsRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="Event fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Event ID.** CRM event ID.
</ResponseField>

<ResponseField name="EmployeeID" field-type="integer">
**Responsible employee ID.** Employee in charge of the event; omitted when NULL.
</ResponseField>

<ResponseField name="CustomerID" field-type="integer">
**Customer ID.** Customer the event belongs to.
</ResponseField>

<ResponseField name="EventTypeID" field-type="integer">
**Event type ID.** Event type.
</ResponseField>

<ResponseField name="ContactID" field-type="integer">
**Contact ID.** Customer contact person of the event; omitted when none.
</ResponseField>

<ResponseField name="OpportunityID" field-type="integer">
**Opportunity ID.** Linked sales opportunity; omitted when none.
</ResponseField>

<ResponseField name="OpportunitySubject" field-type="string">
**Opportunity subject.** Subject of the linked opportunity.
</ResponseField>

<ResponseField name="Subject" field-type="string">
**Subject.** Event subject. Not cleaned of XML-forbidden characters.
</ResponseField>

<ResponseField name="Description" field-type="string">
**Description.** Event description - free-text CRM notes, may contain personal data about contacts. Not cleaned of XML-forbidden characters.
</ResponseField>

<ResponseField name="Date" field-type="string">
**Event date.**
</ResponseField>

<ResponseField name="Status" field-type="integer">
**Event status.** The status parameter filters on it.
</ResponseField>

</Expandable>
</ResponseField>
