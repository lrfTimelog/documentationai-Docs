Returns the account's mileage registrations with route, distance, vehicle, rate and amounts.

| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetMileageRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Filters: customer, project, employee, employee department, date range, self-paid flag, vehicle and rate.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="customerID" field-type="integer" required="true">
Customer of the trip's project. 0 = no filter.
</ResponseField>

<ResponseField name="projectID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="employeeID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="departmentID" field-type="integer" required="true">
The employee's current department INCLUDING sub-departments. Employees without a department never match. 0 = no filter.
</ResponseField>

<ResponseField name="startDate" field-type="string">
**Optional.** Send yyyy-MM-dd.
</ResponseField>

<ResponseField name="endDate" field-type="string">
**Optional.** Travel date &lt;= value.
</ResponseField>

<ResponseField name="selfPayment" field-type="integer" required="true">
Use `-1` for no filter.
</ResponseField>

<ResponseField name="travelCarID" field-type="integer" required="true">
Vehicle ID. 0 = no filter.
</ResponseField>

<ResponseField name="transportRateID" field-type="integer" required="true">
Mileage rate ID. 0 = no filter.
</ResponseField>

## Response

The result is an XML document inside `GetMileageRawResult`: a `tlp:Mileage` root with one `tlp:Mileage` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: Travel date, then employee initials, then customer name.

<ResponseField name="tlp:Mileage" field-type="MileageRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.
