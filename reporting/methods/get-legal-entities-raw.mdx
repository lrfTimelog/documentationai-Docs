description: "Reporting API: Returns the account's legal entities with currency and default country, optionally only active or inactive ones."
---

| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetLegalEntitiesRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

The XML comment's summary says 'price groups'; the method returns legal entities. Low sensitivity.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="status" field-type="integer" required="true">
Active flag compared with IsActive: 0 = inactive, 1 = active, >= 2 = NOTHING; negative = all.
</ResponseField>

## Response

The result is an XML document inside `GetLegalEntitiesRawResult`: a `tlp:LegalEntities` root with one `tlp:LegalEntity` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: None.

<ResponseField name="tlp:LegalEntity" field-type="LegalEntityRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="LegalEntity fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Legal entity ID.** LegalEntityID.
</ResponseField>

<ResponseField name="GUID" field-type="string (attribute)">
**Legal entity GUID.**
</ResponseField>

<ResponseField name="Name" field-type="string">
**Name.** Nullable.
</ResponseField>

<ResponseField name="IsActive" field-type="integer">
**Active.** bit, default 0.
</ResponseField>

<ResponseField name="CurrencyISO" field-type="string">
**Currency.** The legal entity's currency code.
</ResponseField>

<ResponseField name="Country" field-type="string">
**Country.** Default country NAME.
</ResponseField>

</Expandable>
</ResponseField>
