| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetEmployeeNormalWorkingTimeHistoriesRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Only the START is returned; a period ends one minute before the next period's start. Filters: employee USER id and employee status. No ORDER BY: sort by EmployeeUserID + ValidFromDate on the client.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="employeeUserID" field-type="integer" required="true">
USER id. 0 = no filter.
</ResponseField>

<ResponseField name="employeeStatus" field-type="integer" required="true">
0 = inactive employees, 1 = active, any other value = all.
</ResponseField>

## Response

The result is an XML document inside `GetEmployeeNormalWorkingTimeHistoriesRawResult`: a `tlp:EmployeeNormalWorkingTimeHistories` root with one `tlp:EmployeeNormalWorkingTimeHistory` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: None - no ORDER BY.

<ResponseField name="tlp:EmployeeNormalWorkingTimeHistory" field-type="EmployeeNormalWorkingTimeHistoriesRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="EmployeeNormalWorkingTimeHistory fields">

<ResponseField name="ID" field-type="integer (attribute)">
**History entry ID.**
</ResponseField>

<ResponseField name="GUID" field-type="string (attribute)">
**History entry GUID.**
</ResponseField>

<ResponseField name="EmployeeUserID" field-type="integer">
**Employee user ID.** USER id of the employee.
</ResponseField>

<ResponseField name="ValidFromDate" field-type="string">

**Scheme ID.**
