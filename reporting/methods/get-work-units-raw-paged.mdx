---
title: "GetWorkUnitsRawPaged"
description: "Reporting API: Returns one page of the account's project time registrations with total counts on the root."
---

| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetWorkUnitsRawPaged` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | Yes |

## How it works

Otherwise the call silently returns EVERYTHING, exactly like GetWorkUnitsRaw. pageSize has no upper bound.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="workUnitID" field-type="integer" required="true">
Time registration ID. 0 = no filter.
</ResponseField>

<ResponseField name="employeeID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="allocationID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="taskID" field-type="integer" required="true">
Task. 0 = no filter.
</ResponseField>

<ResponseField name="projectID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="departmentID" field-type="integer" required="true">
Department stored on the registration. 0 = no filter.
</ResponseField>

<ResponseField name="startDate" field-type="string">
**Optional.** Send yyyy-MM-dd.
</ResponseField>

<ResponseField name="endDate" field-type="string">
**Optional.** Registration date &lt;= value.
</ResponseField>

<ResponseField name="page" field-type="string">
**Optional.** 1-based page number, sent as a STRING. A page beyond the last returns an empty page whose root reports TotalRecords=0 / TotalPages=0.
</ResponseField>

<ResponseField name="pageSize" field-type="string">
**Optional.** No server maximum.
</ResponseField>

## Errors

The errors every method can return (access denied, operation failed, invalid request) are listed once in [Responses and errors](/reporting/guides/responses-and-errors#errors).

Errors specific to this method:

| HTTP status | What you get | What it means | What to do |
|---|---|---|---|
| 200 | A document that stops in the middle (does not parse to the end) | The extract is sent row by row; a failure after the first rows were sent cuts the document off. | Treat a document that does not parse as failed and repeat the call with a shorter date range. |
