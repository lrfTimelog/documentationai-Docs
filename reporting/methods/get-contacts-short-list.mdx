Returns the account's customer contacts with id and full name.

| | |
|---|---|
| API | Reporting API (short lists) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetContactsShortList` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Filter: customer. Inactive contacts are included and carry no flag; with no filter, contacts without a customer are included too. A contact whose first OR last name is NULL has no FullName.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="customerID" field-type="integer" required="true">
Customer. 0 = no filter; a negative value also means no filter.
</ResponseField>

## Response

The result is an XML document inside `GetContactsShortListResult`: a `tlp:Contacts` root with one `tlp:Contact` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

<ResponseField name="tlp:Contact" field-type="ContactShort[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="Contact fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Contact ID.**
</ResponseField>

<ResponseField name="FullName" field-type="string">
**Full name.** First name + ' ' + last name. The '+' concatenation yields NULL when EITHER part is NULL, so a contact with only a first or only a last name has NO FullName element. Not cleaned of XML-forbidden characters.
</ResponseField>

</Expandable>
</ResponseField>
