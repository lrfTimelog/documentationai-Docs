Returns price groups per legal entity, general or customer-specific.

| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetPriceGroupsRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Sentinels differ from the other extracts: legalEntityId 0 = all and a NEGATIVE value returns nothing; customerId 0 = all, -1 = only general price groups, &lt;= -2 fails with HTTP 500. Low sensitivity.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="legalEntityId" field-type="integer" required="true">
Use `0` for no filter.
</ResponseField>

<ResponseField name="customerId" field-type="integer" required="true">
Use `0` for no filter.
</ResponseField>

## Response

The result is an XML document inside `GetPriceGroupsRawResult`: a `tlp:PriceGroups` root with one `tlp:PriceGroup` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: None.

<ResponseField name="tlp:PriceGroup" field-type="PriceGroupRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="PriceGroup fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Price group ID.**
</ResponseField>

<ResponseField name="GUID" field-type="string (attribute)">
**Price group GUID.**
</ResponseField>

<ResponseField name="Name" field-type="string">
**Name.**
</ResponseField>

<ResponseField name="LegalEntityID" field-type="integer">
**Legal entity ID.** Owning legal entity.
</ResponseField>

<ResponseField name="LegalEntityName" field-type="string">
**Legal entity name.**
</ResponseField>

<ResponseField name="CustomerID" field-type="integer">
**Customer ID.** Customer-specific price group; OMITTED for a general price group.
</ResponseField>

<ResponseField name="CustomerName" field-type="string">
**Customer name.** Omitted for general price groups.
</ResponseField>

<ResponseField name="CurrencyISO" field-type="string">
**Currency.** The price group's currency code.
</ResponseField>

<ResponseField name="IsActive" field-type="integer">
**Active.** Nullable bit - omitted when NULL.
</ResponseField>

</Expandable>
</ResponseField>
