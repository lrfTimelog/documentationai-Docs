| | |
|---|---|
| API | Reporting API (short lists) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetDepartmentsShortList` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

No parameters besides the credential and no filter - active AND inactive departments are returned; the hierarchy is rebuilt from ParentID.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

## Response

The result is an XML document inside `GetDepartmentsShortListResult`: a `tlp:Departments` root with one `tlp:Department` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: Department name, ascending.

<ResponseField name="tlp:Department" field-type="Department[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="Department fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Department ID.**
</ResponseField>

<ResponseField name="Name" field-type="string">
**Department name.** Not cleaned of XML-forbidden characters.
</ResponseField>

<ResponseField name="ParentID" field-type="integer">
**Parent department ID.** Whether top-level departments store NULL or 0 is not established.
</ResponseField>

<ResponseField name="IsActive" field-type="integer">
**Active.** 1 = active; 0 = inactive.
</ResponseField>

<ResponseField name="DepartmentNo" field-type="string">
**Department number.** Omitted when NULL.
</ResponseField>

<ResponseField name="DepartmentManagerUserID" field-type="integer">
**Department manager (user ID).** This is the LOGIN id, NOT the employee id - map through GetEmployeesShortList.
</ResponseField>

<ResponseField name="DepartmentManagerInitials" field-type="string">
**Department manager initials.**
</ResponseField>

<ResponseField name="DepartmentManagerFullName" field-type="string">
**Department manager full name.**
</ResponseField>

</Expandable>
</ResponseField>
