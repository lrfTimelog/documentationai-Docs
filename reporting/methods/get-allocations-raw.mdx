| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetAllocationsRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Filters: allocation, task, employee, project. No status or date filter: completed allocations are always included. Allocations on project TEMPLATES are included too.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="allocationID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="taskID" field-type="integer" required="true">
Task. 0 = no filter.
</ResponseField>

<ResponseField name="employeeID" field-type="integer" required="true">
Allocated employee. 0 = no filter.
</ResponseField>

<ResponseField name="projectID" field-type="integer" required="true">
Project of the allocated task. 0 = no filter.
</ResponseField>

## Response

The result is an XML document inside `GetAllocationsRawResult`: a `tlp:Allocations` root with one `tlp:Allocation` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

<ResponseField name="tlp:Allocation" field-type="AllocationRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="Allocation fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Allocation ID.**
</ResponseField>

<ResponseField name="ProjectID" field-type="integer">
**Project ID.** Project of the allocated task.
</ResponseField>

<ResponseField name="TaskID" field-type="integer">
**Task ID.** The allocated task.
</ResponseField>

<ResponseField name="EmployeeID" field-type="integer">
**Employee ID.** The allocated employee.
</ResponseField>

<ResponseField name="AllocatedHours" field-type="decimal">
**Allocated hours.** Hours allocated to the employee on the task; 0 when not set. CONVERT - four decimals.
</ResponseField>

<ResponseField name="HourlyRateID" field-type="integer">
**Hourly rate ID.** The contract hourly rate the allocation uses. Not in the published XSD.
</ResponseField>

<ResponseField name="HourlyRate" field-type="decimal">
**Hourly rate.** Four decimals. SENSITIVE: billing rate per employee allocation.
</ResponseField>

<ResponseField name="TaskIsFixedPrice" field-type="integer">
**Task is fixed price.**
</ResponseField>

<ResponseField name="IsActive" field-type="integer">
**Allocation is active.**
</ResponseField>

<ResponseField name="StartsAt" field-type="string">
**Allocation start.** Allocation start date.
</ResponseField>

<ResponseField name="EndsAt" field-type="string">
**Allocation end.** Allocation end date.
</ResponseField>

</Expandable>
</ResponseField>
