| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetMilestoneTypesRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Filter: milestoneTypeID.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="milestoneTypeID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="status" field-type="integer" required="true">
Use `-1` for no filter. The XML comment's '0 uncompleted / 1 completed' text is copied from GetMilestonesRaw and does not apply.
</ResponseField>

## Request

<Request uid="rep-getmilestonetypesraw-req" show-lines="true" tabs={["XML", "cURL", "Python"]}>

```xml
POST /{account}/Service.asmx HTTP/1.1
Host: app{server-number}.timelog.com
Content-Type: text/xml; charset=utf-8
SOAPAction: "http://www.timelog.com/ws/tlp/v4_4/GetMilestoneTypesRaw"

<soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/"
               xmlns:tlp="http://www.timelog.com/ws/tlp/v4_4">
  <soap:Body>
    <tlp:GetMilestoneTypesRaw>
      <tlp:siteCode>{siteCode}</tlp:siteCode>
      <tlp:apiID>{apiID}</tlp:apiID>
      <tlp:apiPassword>{apiPassword}</tlp:apiPassword>
      <tlp:milestoneTypeID>0</tlp:milestoneTypeID>
      <tlp:status>-1</tlp:status>
    </tlp:GetMilestoneTypesRaw>
  </soap:Body>
</soap:Envelope>
```

```bash
curl -X POST "https://app{server-number}.timelog.com/{account}/Service.asmx" \

  -H 'SOAPAction: "http://www.timelog.com/ws/tlp/v4_4/GetMilestoneTypesRaw"' \

```

```python
import requests

URL = "https://app{server-number}.timelog.com/{account}/Service.asmx"
SOAP_ACTION = '"http://www.timelog.com/ws/tlp/v4_4/GetMilestoneTypesRaw"'

envelope = """<soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/"
               xmlns:tlp="http://www.timelog.com/ws/tlp/v4_4">
  <soap:Body>
    <tlp:GetMilestoneTypesRaw>
      <tlp:siteCode>{siteCode}</tlp:siteCode>
      <tlp:apiID>{apiID}</tlp:apiID>
      <tlp:apiPassword>{apiPassword}</tlp:apiPassword>
      <tlp:milestoneTypeID>0</tlp:milestoneTypeID>
      <tlp:status>-1</tlp:status>
    </tlp:GetMilestoneTypesRaw>
  </soap:Body>
</soap:Envelope>"""

response = requests.post(
    URL,
    data=envelope.encode("utf-8"),
    headers={"Content-Type": "text/xml; charset=utf-8", "SOAPAction": SOAP_ACTION},
    timeout=300,
)
rows = parse_result(response)  # see "Responses and errors"
```

</Request>

## Response

The result is an XML document inside `GetMilestoneTypesRawResult`: a `tlp:MilestoneTypes` root with one `tlp:MilestoneType` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: Milestone type ID ascending.

<ResponseField name="tlp:MilestoneType" field-type="MilestoneTypesRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="MilestoneType fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Milestone type ID.**
</ResponseField>

<ResponseField name="Name" field-type="string">
**Name.** Milestone type name.
</ResponseField>

<ResponseField name="IsActive" field-type="integer">
**Is active.** Active flag of the type. The status parameter does NOT filter on it.
</ResponseField>

</Expandable>
</ResponseField>
