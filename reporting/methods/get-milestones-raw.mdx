---
title: "GetMilestonesRaw"
description: "Reporting API: Returns the account's non-recurring project milestones with date, responsible employee, completion and department."
---

| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetMilestonesRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

Filters: milestone, project, completed status.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="milestoneID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="projectID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

<ResponseField name="status" field-type="integer" required="true">
Use `-1` for no filter. Completion flag; sent when >= 0.
</ResponseField>


```python
import requests

URL = "https://app{server-number}.timelog.com/{account}/Service.asmx"
SOAP_ACTION = '"http://www.timelog.com/ws/tlp/v4_4/GetMilestonesRaw"'

envelope = """<soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/"
               xmlns:tlp="http://www.timelog.com/ws/tlp/v4_4">
  <soap:Body>
    <tlp:GetMilestonesRaw>
      <tlp:siteCode>{siteCode}</tlp:siteCode>
      <tlp:apiID>{apiID}</tlp:apiID>
      <tlp:apiPassword>{apiPassword}</tlp:apiPassword>
      <tlp:milestoneID>0</tlp:milestoneID>
      <tlp:projectID>0</tlp:projectID>
      <tlp:status>-1</tlp:status>
    </tlp:GetMilestonesRaw>
  </soap:Body>
</soap:Envelope>"""

response = requests.post(
    URL,
    data=envelope.encode("utf-8"),
    headers={"Content-Type": "text/xml; charset=utf-8", "SOAPAction": SOAP_ACTION},
    timeout=300,
)
rows = parse_result(response)  # see "Responses and errors"
```

</Request>

## Response

The result is an XML document inside `GetMilestonesRawResult`: a `tlp:Milestones` root with one `tlp:Milestone` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: Project ID, then the milestone's SortOrder.

<ResponseField name="tlp:Milestone" field-type="MilestonesRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="Milestone fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Milestone ID.**
</ResponseField>

<ResponseField name="MilestoneTypeID" field-type="integer">
**Milestone type ID.**
</ResponseField>

<ResponseField name="ProjectID" field-type="integer">
**Project ID.** Project of the milestone.
</ResponseField>

<ResponseField name="ProjectName" field-type="string">
**Project name.** Project name.
</ResponseField>

<ResponseField name="Date" field-type="string">
**Milestone date.** Due date of the milestone.
</ResponseField>

<ResponseField name="ResponsibleEmployeeID" field-type="integer">
**Responsible employee ID.** Employee responsible for the milestone.
</ResponseField>

<ResponseField name="ResponsibleEmployeeName" field-type="string">
**Responsible employee name.**
</ResponseField>

<ResponseField name="Text" field-type="string">
**Text.** Milestone text.
</ResponseField>

<ResponseField name="Completed" field-type="integer">
**Completed.** Completion flag. The status parameter filters on it.
</ResponseField>

<ResponseField name="WBSNo" field-type="string">
**WBS number.** WBS number of the milestone.
</ResponseField>

<ResponseField name="SortOrder" field-type="integer">
**Sort order.**
</ResponseField>

<ResponseField name="DepartmentID" field-type="integer">
**Department ID.** Department of the milestone. Not in the published XSD.
</ResponseField>

</Expandable>
</ResponseField>
