| | |
|---|---|
| API | Reporting API (short lists) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetCustomersShortList` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

No joins - customers GetCustomersRaw drops ARE listed. Suppliers and partners are included; narrow with a customer status whose CustomerStatusType is 1.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="customerStatusID" field-type="integer" required="true">
Use `-1` for no filter. Customer status. 'All' = -1; sent when > -1. NOTE: 0 IS sent and matches nothing - the result is empty. Same rule as GetCustomersRaw.
</ResponseField>

<ResponseField name="accountManagerID" field-type="integer" required="true">
0 = no filter.
</ResponseField>

import requests

    <tlp:GetCustomersShortList>

## Response

The result is an XML document inside `GetCustomersShortListResult`: a `tlp:Customers` root with one `tlp:Customer` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: Company name, then customer number, ascending.

<ResponseField name="tlp:Customer" field-type="CustomerShort[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="Customer fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Customer ID.**
</ResponseField>

<ResponseField name="Name" field-type="string">
**Company name.** Not cleaned of XML-forbidden characters.
</ResponseField>

<ResponseField name="No" field-type="string">
**Customer number.**
</ResponseField>

</Expandable>
</ResponseField>
