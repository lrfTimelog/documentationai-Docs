| | |
|---|---|
| API | Reporting API (raw extracts) |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/Service.asmx` |
| SOAPAction | `http://www.timelog.com/ws/tlp/v4_4/GetHourlyRatesRaw` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | `siteCode`, `apiID` and `apiPassword` as the first three parameters. See [Authentication](/reporting/guides/authentication) |
| Changes data | No. Safe to retry. |
| Paging | No: the whole result comes in one response. Narrow it with the filters. |

## How it works

NOT the price-list rates behind GetEmployeesRaw.DefaultHourlyRateID. Filters: CustomerID, Status. CurrencyISO is the PROJECT currency. BILLING RATES.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="siteCode" field-type="string" required="true">
Your account's site code, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiID" field-type="string" required="true">
The Reporting API ID, from the Reporting API settings.
</ResponseField>

<ResponseField name="apiPassword" field-type="string" required="true">
The Reporting API password, from the Reporting API settings.
</ResponseField>

<ResponseField name="CustomerID" field-type="integer" required="true">
The rate's project's customer. 0 = no filter.
</ResponseField>

<ResponseField name="Status" field-type="integer" required="true">
Active flag: 0 = inactive; ANY positive value = active; negative = all.
</ResponseField>

## Response

The result is an XML document inside `GetHourlyRatesRawResult`: a `tlp:HourlyRates` root with one `tlp:HourlyRate` element per record. Check the [response format](/reporting/guides/responses-and-errors) first: the same slot also carries the empty result and errors.

Order: None.

<ResponseField name="tlp:HourlyRate" field-type="HourlyRateRaw[]">
One element per record. Fields without a value are left out of the element, so treat every field as optional.

<Expandable title="HourlyRate fields">

<ResponseField name="ID" field-type="integer (attribute)">
**Hourly rate ID.** NOT the price-list rate id that GetEmployeesRaw.DefaultHourlyRateID carries.
</ResponseField>

<ResponseField name="GUID" field-type="string (attribute)">
**Hourly rate GUID.**
</ResponseField>

<ResponseField name="Name" field-type="string">
**Name.** Rate name; not cleaned of XML-forbidden characters.
</ResponseField>

<ResponseField name="Amount" field-type="decimal">
**Amount.** Rate per hour, DECIMAL unconverted. HIGH sensitivity: billing rate.
</ResponseField>

<ResponseField name="CurrencyISO" field-type="string">
**Currency.** The PROJECT's currency code.
</ResponseField>

<ResponseField name="IsActive" field-type="integer">
**Active.** bit.
</ResponseField>

<ResponseField name="PriceGroupID" field-type="integer">
**Price group ID.**
</ResponseField>

<ResponseField name="PriceGroupName" field-type="string">
**Price group name.**
</ResponseField>

<ResponseField name="ProjectID" field-type="integer">
**Project ID.** The rate's contract's project. Not in the published XSD.
</ResponseField>

<ResponseField name="ContractID" field-type="integer">
**Contract ID.** The contract the rate belongs to. Not in the published XSD.
</ResponseField>

<ResponseField name="CustomerID" field-type="integer">
**Customer ID.** The project's customer.
</ResponseField>

<ResponseField name="CustomerName" field-type="string">
**Customer name.** Current company name.
</ResponseField>

</Expandable>
</ResponseField>
