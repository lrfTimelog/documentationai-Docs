Many Reporting API fields hold a number that stands for a status or a type. This page lists what each number
means. The method pages link the fields they return.

<Callout kind="info">Values can be added over time. Treat a number you do not know as "other" instead of
failing.</Callout>

## Approval status

The approval state of a time registration. Field: `ApprovedStatus`.

Returned by [GetWorkUnitsRawPaged](/reporting/methods/get-work-units-raw-paged), [GetWorkUnitsRaw](/reporting/methods/get-work-units-raw).

| Value | Name | Meaning |
|---|---|---|
| `0` | Open | The timesheet is open. Rejected and resubmitted registrations also show as open. |
| `10` | Closed | The employee has closed (submitted) the timesheet. Not yet approved. |
| `20` | Project Manager Approved | Approved by the project manager. |
| `30` | Employee Manager Approved | Approved by the employee's manager. |

## Billable status

Whether a time registration is billable, combined with whether its task is billable. Field: `BillableStatus`.

Returned by [GetWorkUnitsRawPaged](/reporting/methods/get-work-units-raw-paged), [GetWorkUnitsRaw](/reporting/methods/get-work-units-raw).

| Value | Name | Meaning |
|---|---|---|
| `-3` | Non Billable Registration On Billable Task With Zero Hourly Rate | Billable task. The registration is marked non-billable and its registered amount is 0. |
| `-2` | Billable Registration On Non Billable Task | Non-billable task. The registration is not marked non-billable. |
| `-1` | Non Billable Registration On Non Billable Task | Non-billable task. The registration is marked non-billable. |
| `1` | Billable Registration On Billable Task | Billable task. Every case not covered by -3 or 2. |
| `2` | Non Billable Registration On Billable Task | Billable task. The registered amount is written off to 0. |

## Time registration invoice status

Whether a time registration has been put on a voucher or an invoice. Field: `InvoiceStatus`.

Returned by [GetWorkUnitsRawPaged](/reporting/methods/get-work-units-raw-paged), [GetWorkUnitsRaw](/reporting/methods/get-work-units-raw).

| Value | Name | Meaning |
|---|---|---|
| `0` | Bookable | Not yet on a voucher or invoice - can still be invoiced. |
| `1` | Added To Voucher | Included on an invoice voucher (draft) that is not booked as an invoice. |
| `2` | Added To Invoice | Included on an invoice. |

## Absence code type

The kind of absence a time-off registration records. Field: `AbsenceCodeType`.

Returned by [GetTimeOffRegistrationsRaw](/reporting/methods/get-time-off-registrations-raw).

| Value | Name | Meaning |
|---|---|---|
| `1` | Illness | Sick leave. This is health data: handle it with extra care. |
| `2` | Holiday | Holiday / vacation. |
| `3` | Absence Non Compensated | Absence without pay compensation. |
| `4` | Absence Compensated | Absence with pay compensation. |

## Contract type

The contract model of a project contract. Field: `ContractModelType`.

Returned by [GetContractsRaw](/reporting/methods/get-contracts-raw).

| Value | Name | Meaning |
|---|---|---|
| `1` | Time Material Basic | Time and material, standard agreement. |
| `2` | Fixed Price Basic | Fixed price, standard agreement. |
| `3` | Time Material Account End Balancing | Time and material on account, balanced at the end. |
| `4` | Time Material Account Periodic Balancing | Time and material on account, balanced periodically (recurrence contract). |
| `5` | Prepaid Services | Prepaid hours (time and material). |
| `6` | Task Driven Revenue | Fixed price, revenue requested per task. |
| `7` | Continuous Service | Fixed price, revenue requested per period (recurrence contract). |
| `8` | Continuous Item Invoicing | Fixed price, volume invoicing (recurrence contract). |
| `20` | Recurring Product Contract | System contract for expenses generated from recurring product sales. |

## Customer status type

Where customers with this status are shown. The value is a set of flags: add values together to combine them. Field: `CustomerStatusType`.

Returned by [GetCustomerStatusShortList](/reporting/methods/get-customer-status-short-list).

| Value | Name | Meaning |
|---|---|---|
| `0` | None | In no group. |
| `1` | Is Shown In Customers | Customer status - customers carry it. |
| `2` | Is Shown In Suppliers | Supplier status - suppliers are customers with such a status. |
| `8` | Is Shown In Leads | Offered for leads. |
| `16` | Is Multi Customer Projects | System status used for projects with more than one customer. |
