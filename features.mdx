## Time Tracking Workflows

Set up time tracking in minutes. You assign tasks to projects, log hours via timer or manual entry, and review entries for accuracy.

<Steps>
  <Step title="Create a Project" icon="plus">
    Navigate to the Projects dashboard and click New Project. Enter details like client name, start date, and budget.
  </Step>
  <Step title="Start Timer" icon="play">
    Select a task within the project. Click the timer to begin tracking time automatically.
  </Step>
  <Step title="Log and Review" icon="check-circle">
    Stop the timer and add notes. Review daily logs to ensure completeness.
  </Step>
</Steps>

<Callout kind="tip">
  Enable mobile app sync for on-the-go tracking. Use tags like `urgent` or `billable` for better categorization.
</Callout>

## Reporting and Analytics

Unlock insights with customizable dashboards. Filter data by project, client, or time period to spot trends.

<CodeGroup tabs="SQL,API">
  ```sql
  SELECT 
    project.name,
    SUM(time_entries.hours) as total_hours,
    AVG(time_entries.rate) as avg_rate
  FROM time_entries
  JOIN project ON time_entries.project_id = project.id
  GROUP BY project.name
  ORDER BY total_hours DESC;
  ```
  ```javascript
  const response = await fetch('https://api.example.com/reports/hours', {
    headers: { 'Authorization': 'Bearer YOUR_TOKEN' }
  });
  const data = await response.json();
  console.log(data.projects);
  ```
</CodeGroup>

<Expandable title="Advanced Filters" default-open="false">
