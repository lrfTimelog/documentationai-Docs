<Update label="2024-10-15" description="v2.5.0" tags={["feature", "improvement"]}>
## New Features

- Added real-time time tracking dashboard with live updates for teams.
- Introduced automated invoice generation from project time entries.
- New resource allocation calendar view for better project staffing.

## Improvements

- Enhanced reporting with customizable widgets and export to PDF/Excel.
- Optimized mobile app performance for faster time entry on iOS and Android.

## Bug Fixes

- Fixed sync issues between web and mobile time logs.
- Resolved invoicing calculation errors for multi-currency projects.
</Update>

<Update label="2024-09-20" description="v2.4.0" tags={["feature", "bugfix"]}>

## How to Update

<Steps>
  <Step title="Check Compatibility" icon="check-circle">
    Review the [release notes](https://docs.timelog.com/changelog) for breaking changes.
  </Step>
  <Step title="Backup Data" icon="database">
    Export your projects and time logs via the admin panel.
  </Step>
  <Step title="Run Update" icon="download-cloud">
    
````bash
docker-compose pull
docker-compose up -d
````
    
  </Step>
  <Step title="Verify" icon="search">
    Test key features like time entry and reporting.
  </Step>
</Steps>
