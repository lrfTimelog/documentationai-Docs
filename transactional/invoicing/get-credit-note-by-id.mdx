## How it works

Reads the credit note with this integer ID. Return holds exactly one CreditNote on success. An unknown ID is an Error envelope, not an empty Return. Amounts are in the credit note's own currency and negative when it credits an invoice. For a DRAFT, NetAmount / AmountDue / Rounding are recalculated from the lines on this read.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="id" field-type="integer" required="true">
Integer ID of the credit note. An unknown ID is an error.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>
