| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |

## How it works

Looks up the mapping stored for INVOICES and returns that invoice. The match is exact on the key; the system must be registered on the account. The returned invoice is INCOMPLETE: InvoiceLines is empty, VATIncluded is 0, a draft's totals are the stored ones, and an overdue invoice can still say Booked. The invoice's external keys are loaded but not returned. Call GetInvoiceByGUID with the returned GUID for the full invoice.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="externalKey" field-type="string" required="true">
The external system's key for the invoice, as stored by the mapping.

</ResponseField>

<ResponseField name="systemName" field-type="string" required="true">
Name of the registered external system the key belongs to.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Error | 40001 | Error during call on TimeLog.API, Message 'Invoice not found (Key: "\{externalKey\}", SystemName: "\{systemName\}"' | No mapping, more than one invoice mapped to the key, or the system name does not match. | — |
| Error | 40001 | Error during call on TimeLog.API, Message 'Unable to retrieve invoiceDTO with GUID:\{guid\} In Stored Procedure: …' | The mapping points at an invoice GUID that no longer exists. | Check the GUID. |
