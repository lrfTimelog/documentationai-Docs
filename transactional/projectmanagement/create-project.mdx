## How it works

If the project picked up a legacy default hourly rate it is mapped to the main contract's rate. Finally the project is moved to the account's default project status for external projects. MainContractID selects the main contract MODEL on create (1 time & material... 8 continuous item invoicing; any other value = time & material) - see the Project schema.

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Error | 40001 | Error during call on TimeLog.API, Message 'Missing Role: User can create project!' | The user may not create this project. | Give the integration user a role with project create rights covering the project. |
| Error | 30171 | Error during call on TimeLog.API, Message 'Project number cannot be empty' | No empty, no number series, empty numbers not allowed. | Send the project number on every create / update. |
| Error | 37885 | Error during call on TimeLog.API, Message 'The standard hourly rate on project is invalid.' | The legacy default hourly rate cannot be mapped - the project IS created. | — |
| Error | 40001 | Error during call on TimeLog.API, Message 'This API endpoint is disabled due to the Currency Matrix feature being turned on. Please upgrade your Project API version to 1_8 or later.' | — | Move to the version named in the message. |
