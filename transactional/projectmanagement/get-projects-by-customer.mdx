## How it works

Resolves the customer GUID to its integer ID and runs the same project search as GetProjects with only the customer, status and active filters.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="customerGuid" field-type="guid" required="true">
GUID of the customer. Unknown -> error.

</ResponseField>

<ResponseField name="projectStatusID" field-type="integer">
**Optional.** Default 0 = Quote ONLY; -1 = all statuses. Only projects in this status.

</ResponseField>

<ResponseField name="includeInactiveProjects" field-type="boolean">
**Optional.** Default false = active projects only. true = active and inactive projects.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>
