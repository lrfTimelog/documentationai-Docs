| Paging | Yes, up to 500 per page |

## How it works

Like GetWorkPaged, restricted to registrations whose PROJECT has an external-system mapping for `systemName` and whose ApprovedStatus equals `approvalLevel` exactly. Absence registrations are never returned.

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Error | 40001 | Error during call on TimeLog.API, Message 'The current user is not allowed to fetch registrations from other users' | Return is empty, IsReturnPaged true, TotalPageCount -1. | — |
| Invalid | 40004 | V1_\{n\} is deprecated. Please upgrade to V1_\{m\} or later. | Nothing is read or written and the token is NOT checked. | Call the same operation on the current version. |
