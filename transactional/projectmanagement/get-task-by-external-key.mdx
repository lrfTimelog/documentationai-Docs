Returns the task mapped to an external system's key, with its external keys.

| | |
|---|---|
| Service | Project management 1.8 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/ProjectManagement/V1_8/ProjectManagementServiceSecure.svc` |
| SOAPAction | `GetTaskByExternalKeyRequest` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |

## How it works

Resolves to the task's GUID through the external-system mapping, loads the task and its external keys and returns it.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="key" field-type="string" required="true">
The task's ID in the external system.

</ResponseField>

<ResponseField name="systemName" field-type="string" required="true">
 

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Error | 40001 | Error during call on TimeLog.API, Message 'The external key "\{externalID\}" was not found for the chosen external system "\{systemName\}".' | The system exists but no task is mapped to this key. | Create the contact first; a not-found is a normal outcome for sync look-ups. |
