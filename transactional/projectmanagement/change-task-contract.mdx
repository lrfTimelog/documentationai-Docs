| Authentication | A token from [GetToken](/transactional/guides/authentication) |

## How it works

On success the task's rates and its allocations' rates are resolved on the target contract, open registrations are re-pointed to the new rates, the billing plan is adapted to the target contract model and the budgets of the old and new contract are recalculated. Only the task itself moves - not its sub-tasks.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="taskGuid" field-type="guid" required="true">
GUID of the task.

</ResponseField>

<ResponseField name="projectSubContractId" field-type="integer" required="true">
Integer ID of the target contract - an Active contract of the task's own project. The task's current contract = no-op.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Error | 40001 | Error during call on TimeLog.API, Message 'Invalid contract move. The target contract belongs to a different project (Expected project ID: \{current contract's project\}, Was: \{target contract's project\})' | ChangeTaskContract with a contract of another project. Nothing is changed. | Use a contract of the task's own project. |
| Error | 40001 | Error during call on TimeLog.API, Message 'It is not allowed to change project sub contract on a Parent Task, TaskID='\{TaskID\}'' | Nothing is changed. | — |
| Error | 40001 | Error during call on TimeLog.API, Message 'Unable to change task project sub contract from:'\{current contract\}' to: '\{target contract\}', Reason: \{reason\}.' | Contract-sub-group sub-task, or invoiced / vouchered registrations or payments. | Create a new task on the target contract for future time. |
| Error | 40001 | Error during call on TimeLog.API, Message 'Since the target contract is completed or cancelled, the task cannot be moved to target contract' | ChangeTaskContract to a Completed or Cancelled contract. Nothing is changed. | Reopen the contract or choose an active one. |
| Error | 40001 | Error during call on TimeLog.API, Message 'Unable to change the contract on the task because the task has time registration(s) or payment(s) that falls within closed accounting period' | ChangeTaskContract on a task with time or payments in a closed accounting period. Nothing is changed. | Create a new task on the target contract for future time. |
