## How it works

The project number is the caller's projectNo unless useProjectNumberSeries = true. What is copied from the template: ALWAYS its contracts with their contract hourly rates and contract customers, its products and recurrences; tasks and milestones only with useTasksAndMileStonesFromTemplate; the resource group only with useResourceGroupFromTemplate; allocations only when useAllocationsFromTemplate AND the two previous flags are true; budgets and payment plans only with usePaymentPlanFromTemplate. Afterwards the project is moved to the account's default external-project status.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="projectTemplateName" field-type="string" required="true">
Name of the project template. Empty -> 10002; null -> null-reference error.

</ResponseField>

<ResponseField name="projectName" field-type="string" required="true">
Name of the new project. Empty -> 10002.

</ResponseField>

<ResponseField name="projectNo" field-type="string">
**Conditional.** Project number of the new project.

</ResponseField>

<ResponseField name="customerName" field-type="string" required="true">
Customer name, matched EXACTLY; with duplicates one of them is used. Unknown / empty -> 30053.

</ResponseField>

<ResponseField name="legalEntityID" field-type="guid" required="true">
GUID of the legal entity. Unknown or all zeros -> 30097.

</ResponseField>

<ResponseField name="priceGroupID" field-type="guid" required="true">
GUID of one of the legal entity's price groups; sets the currency list and the currency. Otherwise -> 30098.

</ResponseField>

<ResponseField name="projectManagerInitials" field-type="string" required="true">
Empty -> 10002; unknown -> 30050.

</ResponseField>

<ResponseField name="accountManagerInitials" field-type="string" required="true">
Unknown -> 30051.

</ResponseField>

<ResponseField name="handledByDepartmentNo" field-type="string">
**Optional.** Default empty = not set. Department number of the handling department. Unknown -> 30054.

</ResponseField>

<ResponseField name="orderedByDepartmentNo" field-type="string">
**Optional.** Default empty = not set. Department number of the ordering department. Unknown -> 30054.

</ResponseField>

<ResponseField name="useProjectNumberSeries" field-type="boolean" required="true">
 

</ResponseField>

<ResponseField name="useTasksAndMileStonesFromTemplate" field-type="boolean" required="true">
Copy the template's tasks and milestones.

</ResponseField>

<ResponseField name="useResourceGroupFromTemplate" field-type="boolean" required="true">
Copy the template's resource group.

</ResponseField>

<ResponseField name="useAllocationsFromTemplate" field-type="boolean" required="true">
Copy allocations - effective ONLY when useTasksAndMileStonesFromTemplate and useResourceGroupFromTemplate are also true.

</ResponseField>

<ResponseField name="usePaymentPlanFromTemplate" field-type="boolean" required="true">
Copy budgets and payment plans.

</ResponseField>

<ResponseField name="source" field-type="integer">
**Optional.** Default `0`.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>
