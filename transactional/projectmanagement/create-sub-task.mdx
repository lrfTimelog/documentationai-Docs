Creates a task as the last sub-task of a parent task, on the parent's contract by default.

| | |
|---|---|
| Service | Project management 1.8 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/ProjectManagement/V1_8/ProjectManagementServiceSecure.svc` |
| SOAPAction | `CreateSubTaskRequest` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | Yes |
| Safe to retry | Send a client-generated Task.ID: a retried create that went through fails instead of duplicating. |

## How it works

Loads the project, loads the parent task by integer ID and finds the task with the SAME WBS NUMBER in the project, builds a new sub-task numbered '&lt;parent WBS>&lt;n+1>', maps the Task you send, defaults ProjectSubContractID to the parent's contract, applies HourlyRateID and saves the project. With Details.WBS set the project is re-loaded and the sub-task is inserted at that WBS number instead. A task that already has allocations cannot become a parent.

|---|---|---|---|---|
| Error | 40001 | Error during call on TimeLog.API, Message 'ParentTaskId parameter is mandatory for this API service.' | parentTaskId &lt;= 0. | Send the parent's integer TaskID. |
| Error | 40001 | Error during call on TimeLog.API, Message '\{rule text\}' - one message per violated rule, then 'Task is not in an invalid state to be saved' | Name / dates missing, end before start, or the parent already has allocations. | Send Name, StartDate and EndDate; create sub-tasks only under tasks without allocations. |

| Error | 40001 | Error during call on TimeLog.API, Message 'The specified HourlyRateID \{HourlyRateID\} do not exist, is in-active or not in the Price List of the Project related to the specified ProjectID: \{ProjectID\}' | HourlyRateID not valid for the project. | Send 0, or a rate valid for the project's price list. |
| Error | 40001 | Error during call on TimeLog.API, Message 'TypeID has to be > 0 on Task. Current value: \{TaskTypeID\}' | — | Send a TaskTypeID. |
