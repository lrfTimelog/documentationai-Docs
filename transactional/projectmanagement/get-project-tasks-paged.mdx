## How it works

With projectGuid = all zeros, the tasks of EVERY project are returned. No filter on project or task status - completed, cancelled and inactive tasks are included. No privilege is checked.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.
