## How it works

References are matched BY NAME, as in CreateEmployee: normal working time, holiday calendar, allowance legislation, employee type; the cost price within the employee's legal entity; the hourly rate resolved for the employee's legal entity. The first failing look-up stops the call. Changing the user name changes the LOGIN name. The e-mail is checked for format only - no confirmation is sent to the old or new address. The title is limited to 50 characters. User name / initials must stay unique; a clash with an INACTIVE user is tolerated only when the call leaves both unchanged.

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|

| Error | 40001 | Error during call on TimeLog.API, Message 'The \{normal working week \| holiday calendar \| allowance settings \| employee type \| cost price \| hourly rate\} was not found' / 'The department is not found' | A working time / holiday calendar / allowance / employee type / cost price / hourly rate name was not found. | — |

| Error | 40001 | Error during call on TimeLog.API, Message 'The title exceeds the maximum length of 50 characters' | title longer than 50 characters. | Shorten the title to 50 characters. |
