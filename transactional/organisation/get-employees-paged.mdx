| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Organisation/V1_9/OrganisationServiceSecure.svc` |
| SOAPAction | `http://www.timelog.com/api/tlp/v1_9/OrganisationService/GetEmployeesPaged` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Permissions | The result includes private address / telephone and cost price / hourly rate of every employee. |
| Changes data | No |
| Safe to retry | Yes |
| Paging | Yes, up to 100 per page |

## How it works

Loads EVERY employee of the account, converts each to an Employee record, and only then cuts out the requested page. Each call therefore costs the whole employee list, whatever the page size. API users, system users and other non-employee user types are not included. There is no filter, no 'modified since' and no scoping to the caller - every caller sees every employee.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="page" field-type="integer" required="true">
1-based page number. 0 or negative behaves like 1. Beyond the last page -> empty Return.

</ResponseField>

<ResponseField name="pageSize" field-type="integer" required="true">
Employees per page; values above 100 are silently capped at 100. 0 or negative -> empty Return and a meaningless TotalPageCount.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Invalid | 15000 | An error occurred when trying to retrieve all employees. Try again and if the issue persists contact support. | Data-layer failure while loading employees. | Retry later; contact support if it persists. |
