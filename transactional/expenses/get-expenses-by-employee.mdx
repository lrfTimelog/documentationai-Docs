## How it works

Returns every expense of the employee identified by initials whose PurchaseDate is between from and to, both INCLUSIVE, ordered by purchase date. No paging: the whole period comes back in one response. Approval / booking state is not on the wire.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="initials" field-type="string" required="true">
Initials of the employee whose expenses to return. Unknown initials fail with Error 40001.

</ResponseField>

<ResponseField name="from" field-type="dateTime" required="true">
Start of the period on PurchaseDate. Omitted -> 0001-01-01 -> data-layer error.

</ResponseField>

<ResponseField name="to" field-type="dateTime" required="true">
End of the period on PurchaseDate. A to-value at midnight includes expenses dated that day only if they are stored without a time part.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Error | 40001 | Error during call on TimeLog.API, Message 'The current user do not have the right privileges to get expenses for other users' | initials of another employee without the 'all registrations' privilege. | Ask for your own initials, or use a user with the 'all registrations' privilege. |
| Error | 40001 | Error during call on TimeLog.API, Message 'Unable to retrieve result from … with ID \{employee id\}' | — | Send both dates. |
