Returns all payment methods of the account - the values for Expense.PaymentMethodID.

| | |
|---|---|
| Service | Expenses 1.0 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Expenses/V1_0/ExpensesServiceSecure.svc` |
| SOAPAction | `http://www.timelog.com/api/tlp/v1_0/ExpenseService/GetPaymentMethods` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |

## How it works

Whether a method counts as paid by the employee is not returned either.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

## Response

The call returns the standard [response envelope](/transactional/guides/responses-and-errors). **Check `ResponseState` first**: a failed call still returns HTTP 200.

<ResponseField name="ResponseState" field-type="string" required="true">
`Success`, `Invalid` or `Error`.
</ResponseField>

<ResponseField name="ErrorCode" field-type="integer">
`0` on success, otherwise the error code. See [Errors](#errors).
</ResponseField>

<ResponseField name="Return" field-type="PaymentMethod[]">
Response&lt;PaymentMethod>: Return = all payment methods, by name. Success with an empty Return.

<Expandable title="PaymentMethod fields">

<ResponseField name="ID" field-type="integer">
Integer ID - the value to send as Expense.PaymentMethodID.
</ResponseField>

<ResponseField name="Name" field-type="string">
Display name of the payment method. Personal credit cards of individual employees are listed too, by their configured name.
</ResponseField>

<ResponseField name="IsDefault" field-type="boolean">
true = the account's default payment method for employee expenses.
</ResponseField>

</Expandable>

</ResponseField>
