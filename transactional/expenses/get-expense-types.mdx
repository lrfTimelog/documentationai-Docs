Returns the account's active expense types - the values for Expense.ExpenseTypeID.

| | |
|---|---|
| Service | Expenses 1.0 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Expenses/V1_0/ExpensesServiceSecure.svc` |
| SOAPAction | `http://www.timelog.com/api/tlp/v1_0/ExpenseService/GetExpenseTypes` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |

## How it works

Lists every ACTIVE expense type of the account, across all legal entities, excluding material / subcontractor types. The list is built in two blocks: first the types flagged for travel expenses, then the others, each block sorted by name.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

</ResponseField>
