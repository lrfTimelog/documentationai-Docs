Creates one expense for an employee on a project and returns it.

| | |
|---|---|
| Service | Expenses 1.0 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Expenses/V1_0/ExpensesServiceSecure.svc` |
| SOAPAction | `http://www.timelog.com/api/tlp/v1_0/ExpenseService/InsertExpense` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Permissions | Expenses of other employees: privilege 'all registrations'. |
| Changes data | Yes |
| Safe to retry | Only with an ExternalID: a repeat in the same project legal entity stores nothing. Without ExternalID every call creates a new expense. |

## How it works

Registers an expense on the project given by ProjectNo, for the employee given by EmployeeInitials. The expense goes on the project's main contract. Required: ProjectNo, CurrencyISO, ExpenseTypeID, ProductNo, the employee, PurchaseDate and the amounts. The server computes cost, sales amount and reimbursement in the system, project and legal-entity currencies; the expense number comes from auto-numbering when it is active. On failure ResponseState is Error, code 40001, the reason is in the message text and Return[0] may still hold the expense you sent: check ResponseState. Retry safety: set ExternalID. A second insert with an ExternalID already used in the project's legal entity stores nothing - but also reports Success, so confirm with GetExpensesByEmployee.

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="expense" field-type="Expense" required="true">
The Expense to send. Its fields are listed below.

<Expandable title="Expense fields">

<ResponseField name="ID" field-type="guid">
**Optional.** The expense's stable identifier. On insert: leave empty and the server generates one, or supply your own GUID. On update: identifies the expense to overwrite.
</ResponseField>

<ResponseField name="Comment" field-type="string">
**Optional.** Free-text description of the expense; also part of the generated system text '&lt;type>: &lt;comment>'.
</ResponseField>

<ResponseField name="CurrencyISO" field-type="string" required="true">
'DKK', 'EUR'). PurchasedAmountInCurrency and VATAmount are in this currency.
</ResponseField>

<ResponseField name="CurrencyRate" field-type="double">
**Optional.** EUR to DKK = 746.0). It is stored as the expense's base-reference rate and drives the cost and the REIMBURSEMENT in the employee's currency; it is not validated against the account's exchange-rate table. Do not round-trip the read value into an update unless the employee's legal-entity currency is the system currency.
</ResponseField>

<ResponseField name="ExpenseNo" field-type="string">
**Optional.**
</ResponseField>

<ResponseField name="EmployeeInitials" field-type="string">
**Conditional.** Initials of the employee the expense belongs to. On write this selects the employee; callers without the 'all registrations' privilege must send their OWN initials. Always filled on read.
</ResponseField>

<ResponseField name="ExpenseTypeID" field-type="guid" required="true">
GUID of the expense type.
</ResponseField>

<ResponseField name="ExternalID" field-type="string">
**Optional.** Your system's key for the expense.
</ResponseField>

<ResponseField name="InvoiceNo" field-type="string">
**Optional.** Number of the supplier's invoice / receipt.
</ResponseField>

<ResponseField name="PaymentMethodID" field-type="integer">
**Optional.** Integer ID of the payment method.
</ResponseField>

<ResponseField name="ProductNo" field-type="string" required="true">
Read returns the stored value.
</ResponseField>

<ResponseField name="ProfitPercent" field-type="double">
**Optional.** Markup on the cost used for the billable amount: sales amount = cost ×, cost = PurchasedAmountInCurrency - VATAmount converted to the system / project currency. Read returns 0.
</ResponseField>

<ResponseField name="ProjectNo" field-type="string" required="true">
Number of the project the expense is booked on.
</ResponseField>

<ResponseField name="PurchaseDate" field-type="dateTime" required="true">
Date of the purchase. Used for the exchange-rate look-ups and by GetExpensesByEmployee's period filter.
</ResponseField>

<ResponseField name="PurchasedAmountInCurrency" field-type="double" required="true">
Gross amount paid, INCLUDING VAT, in the CurrencyISO currency. Negative amounts are accepted.
</ResponseField>

<ResponseField name="NonBillable" field-type="boolean">
**Optional.** true = the expense is not to be invoiced to the customer.
</ResponseField>

<ResponseField name="VATAmount" field-type="double">
**Optional.** The VAT part of PurchasedAmountInCurrency, as an AMOUNT in the CurrencyISO currency.
</ResponseField>

<ResponseField name="EmployeeNo" field-type="string">
**Conditional.** Alternative to EmployeeInitials on write. Never filled on read.
</ResponseField>

<ResponseField name="Category" field-type="string">
**Optional.** Personal or company / project expense. Allowed values: `Employee`, `Project`.
</ResponseField>

</Expandable>

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Error | 40001 | Error during call on TimeLog.API, Message 'The current user do not have the right privileges to add expenses for other users' | EmployeeInitials not the caller's and no 'all registrations' privilege. | Register only your own expenses, or use an integration user with the 'all registrations' privilege. |
| Error | 40001 | Error during call on TimeLog.API, Message 'ProductNo is mandatory and is missing' | The value is required although it is never stored. | — |
| Error | 40001 | Error during call on TimeLog.API, Message 'Currency ISO is empty or not valid' | Expense.CurrencyISO is empty or not a currency abbreviation known to the account. | — |
| Error | 40001 | Error during call on TimeLog.API, Message 'Either employee initials or no is needed. Employee not found.' | Neither EmployeeInitials nor EmployeeNo identifies an employee. | Send the initials of an existing employee. |
| Error | 40001 | Error during call on TimeLog.API, Message 'Expense type is not valid' | Expense.ExpenseTypeID is not the GUID of an expense type. | Use an ID returned by GetExpenseTypes. |
| Error | 40001 | Error during call on TimeLog.API, Message 'Project no is missing or project is not found.' | Expense.ProjectNo is missing or no project has that number. | Send the number of an existing project. |
| Error | 40001 | Error during call on TimeLog.API, Message '\{business-rule message\}' | ExternalID ''; project's main contract inactive / prepaid / fixed price with NonBillable; expense type required by the account. | Read the embedded message and fix the expense or the project's contract. |
| Error | 40001 | Error during call on TimeLog.API, Message 'Insert of disbursement failed because there was no payment method set as default for import of expenses!' | InsertExpense with PaymentMethodID 0 on a account without a default payment method for expense import. | Send PaymentMethodID from GetPaymentMethods, or configure a default import payment method. |
| Error | 40001 | Error during call on TimeLog.API, Message 'Insert of disbursement failed!' | — | — |
