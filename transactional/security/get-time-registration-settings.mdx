Returns the account's time-registration display and validation rules, plus whether the caller may register on all tasks.

| | |
|---|---|
| Service | Security 1.2 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Security/V1_2/SecurityServiceSecure.svc` |
| SOAPAction | `GetTimeRegistrationSettingsRequest` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |

## How it works

Built for time-registration clients: which identifiers to show, the formatting locale, whether start/end times are used and may overlap, the additional text field and tracker search limits. UseCaseSensetiveLogin is never filled.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>
