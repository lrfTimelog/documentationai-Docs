## How it works

A normal working time is a named, repeating pattern of expected working hours - one week or two alternating weeks. Employees are assigned a norm; it drives expected hours, flex and capacity. This operation returns EVERY norm of the account with its header and its Days - one entry per day of the pattern with the hours and minutes expected, in pattern order. It is the only API operation that returns a norm's hours per day. It does NOT say which norm an employee has. On V1_1, NormHours is never filled, every Days[].Order is 0 and CanBeDeleted is always false: read the days from Days, by list position.

## Response

The call returns the standard [response envelope](/transactional/guides/responses-and-errors). **Check `ResponseState` first**: a failed call still returns HTTP 200.

<ResponseField name="ResponseState" field-type="string" required="true">
`Success`, `Invalid` or `Error`.
</ResponseField>

<ResponseField name="ErrorCode" field-type="integer">
`0` on success, otherwise the error code. See [Errors](#errors).
</ResponseField>

<ResponseField name="Return" field-type="NormalWorkingTime[]">
Response&lt;NormalWorkingTime>: every norm with its Days, unpaged; 'Successfully called' message added; ResponseState Success. ResponseState Success with an empty Return when the account has no norms.

<Expandable title="NormalWorkingTime fields">

<ResponseField name="CanBeDeleted" field-type="boolean">
Always false: the domain property is never set. Do not use.
</ResponseField>

<ResponseField name="Days" field-type="NormalWorkingTimeDay[]">
The days of the pattern with their expected hours, in pattern order - for a two-week norm the first week's days come before the second week's. Each day's own Order member is always 0: use the list position.
</ResponseField>

<ResponseField name="IsActive" field-type="boolean">
Whether the norm is active. Inactive norms are returned too - filter before assigning.
</ResponseField>

<ResponseField name="IsDefault" field-type="boolean">
Whether this is the account's default norm.
</ResponseField>

<ResponseField name="Name" field-type="string">
Display name of the norm.
</ResponseField>

<ResponseField name="NormHours" field-type="ArrayOfKeyValueOfintdouble">
Use Days.
</ResponseField>

<ResponseField name="NormalWorkingTimeID" field-type="integer">
Integer identifier of the norm - the NormalWorkingTimeID used when assigning a norm to an employee or creating users.
</ResponseField>

<ResponseField name="NormalWorkingTimeType" field-type="string">
Length of the repeating pattern. Allowed values: `OneWeek`, `TwoWeeks`.
</ResponseField>

</Expandable>

</ResponseField>
