Returns the account's holiday calendars.

| | |
|---|---|
| Service | Salary 1.1 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Salary/V1_1/SalaryServiceSecure.svc` |
| SOAPAction | `http://www.timelog.com/api/tlp/v1_1/SalaryService/GetHolidayCalendars` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |

## How it works

Every holiday calendar of the account - a named set of public holidays that employees are assigned to - as ID and name only, ordered by ID. The holiday dates and the description are not returned. The value set for an employee's holiday calendar.
