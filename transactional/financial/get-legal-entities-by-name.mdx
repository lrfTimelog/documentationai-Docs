## How it works

Reads all legal entities and keeps those whose Name is exactly equal to name - an ordinal, case-sensitive comparison in memory: no wildcards, no trimming. Active and inactive legal entities match. No match returns an empty list with ResponseState Success.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="name" field-type="string" required="true">
Exact legal-entity name.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>
