|---|---|
| Service | Financial 1.4 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Financial/V1_4/FinancialServiceSecure.svc` |
| SOAPAction | `http://www.timelog.com/api/tlp/v1_4/FinancialService/GetContractList` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |

## How it works

Contracts of every status are returned; system contracts are not. An unknown project ID returns an EMPTY list with ResponseState Success, not an error.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="projectID" field-type="integer" required="true">
Integer ID of the project. Unknown / 0 = empty list.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

## Response

The call returns the standard [response envelope](/transactional/guides/responses-and-errors). **Check `ResponseState` first**: a failed call still returns HTTP 200.

<ResponseField name="ResponseState" field-type="string" required="true">
`Success`, `Invalid` or `Error`.
</ResponseField>

<ResponseField name="ErrorCode" field-type="integer">
`0` on success, otherwise the error code. See [Errors](#errors).
</ResponseField>

<ResponseField name="Return" field-type="Contract[]">
Response&lt;Contract>: Return = the project's contracts with IsSystem = 0, all statuses, ordered by Name. Unknown project or a project without contracts: Return empty, ResponseState Success.

<Expandable title="Contract fields">

<ResponseField name="ContractID" field-type="integer">
Integer ID of the contract - the value other operations call contractID / ProjectSubContractID.
</ResponseField>

<ResponseField name="ContractModel" field-type="string">
 
</ResponseField>

ID of the account-defined contract type assigned to the contract; 0 when none is set.
</ResponseField>

<ResponseField name="Name" field-type="string">
The contract's name. The list is ordered by this name.
</ResponseField>

<ResponseField name="OrderDate" field-type="dateTime">
Date the contract was ordered, if recorded. No offset is sent; the value is whatever was stored.

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

This operation has no errors of its own beyond the shared ones.
