## How it works

For the project projectID, returns every instance of its recurring project products dated between startDate and endDate. Despite the 'future' naming the window can reach into the past: instances already turned into expenses are included with the expense's purchase date and IsInvoiced = true when invoiced. Only active recurring products are listed, except that already-billed instances of inactive products are still returned. Template projects return nothing. There is no ID of the instance, product or project in the result, and no defined order.

</ResponseField>

<ResponseField name="IsInvoiced" field-type="boolean">
True when the instance has been turned into an expense that is marked invoiced; false for planned instances.
</ResponseField>

<ResponseField name="Name" field-type="string">
Name of the project product.
</ResponseField>

<ResponseField name="PricePerUnit" field-type="double">
 
</ResponseField>

<ResponseField name="ProductNumber" field-type="string">
Accounting product number of the project product; '' when none.
</ResponseField>

<ResponseField name="Quantity" field-type="integer">
Fractional quantities are lost and the totals are computed from the rounded value.
</ResponseField>

<ResponseField name="TotalCostAmount" field-type="double">
Quantity x CostPerUnit, then reduced by Discount % - the SALES discount is applied to the cost too. In CurrencyOfCost.
</ResponseField>

<ResponseField name="TotalSalesAmount" field-type="double">
Quantity x PricePerUnit x / 100, in CurrencyOfSalesPrice. Unrounded double.
</ResponseField>
