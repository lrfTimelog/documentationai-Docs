Sets the Quantity of one payment and recalculates its amount and the contract's plan.

| | |
|---|---|
| Service | Financial 1.4 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Financial/V1_4/FinancialServiceSecure.svc` |
| SOAPAction | `http://www.timelog.com/api/tlp/v1_4/FinancialService/UpdatePaymentQuantity` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | Yes |
| Safe to retry | Yes |

## How it works

Every other member of the sent Payment is ignored. The amount is recalculated from the payment's rate and discount; on fixed-price recurring contracts the contract's payment-plan figures are recalculated, and invoicing potential, currency data and booking status are refreshed. A payment that already has an invoice line is refused. Returns the saved payment.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="payment" field-type="Payment" required="true">
The Payment to send. Its fields are listed below.

<Expandable title="Payment fields">

<ResponseField name="Amount" field-type="double">

**Optional.** Date the payment is due to be invoiced. GetPaymentList filters on it.
</ResponseField>

<ResponseField name="Name" field-type="string">
**Optional.** The installment's name - the text that becomes the invoice line text. Tags in it are replaced when the payment is saved.
</ResponseField>

<ResponseField name="PaymentID" field-type="integer">
**Optional.** Integer ID of the installment. UpdatePaymentQuantity looks the payment up by this value.
</ResponseField>

<ResponseField name="ProjectID" field-type="integer">
**Optional.** Integer ID of the project the payment belongs to.
</ResponseField>

<ResponseField name="ProjectSubContractID" field-type="integer">
**Optional.** Integer ID of the contract whose payment plan holds the payment - the contractID of GetPaymentList.
</ResponseField>

<ResponseField name="Quantity" field-type="double">

</ResponseField>

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Error | 40001 | Error during call on TimeLog.API, Message 'Unable to retrieve result from …' | No payment has PaymentID. | Take PaymentID from GetPaymentList. |
| Error | 40001 | Error during call on TimeLog.API, Message 'The InvoiceableInstallment violates the Business Rules for saving an InvoiceableInstallment' | The payment has an invoice line, or another save rule failed - the rule is not named. | Only change payments that are not yet on an invoice. |
