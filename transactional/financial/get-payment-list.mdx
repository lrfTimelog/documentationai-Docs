Returns the payments of one contract whose invoice date lies in [startDate, endDate].

| | |
|---|---|
| Service | Financial 1.4 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Financial/V1_4/FinancialServiceSecure.svc` |
| SOAPAction | `http://www.timelog.com/api/tlp/v1_4/FinancialService/GetPaymentList` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |

## How it works

Lists the installments of the contract contractID with startDate &lt;= InvoiceDate &lt;= endDate, ordered by installment type, then invoice date. Payments of every state are returned - planned, on a draft invoice and invoiced alike; the contract cannot tell them apart. Amount is in the project's currency, which is not returned. An unknown contract ID returns an empty list with ResponseState Success. 1900-01-01 as either date means 'no bound'; an omitted date fails.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="contractID" field-type="integer" required="true">
Integer ID of the contract. Unknown / 0 = empty list.

</ResponseField>

<ResponseField name="startDate" field-type="dateTime" required="true">
Earliest invoice date. 1900-01-01 = no lower bound. Omitted / before 1753-01-01 = error.

</ResponseField>

<ResponseField name="endDate" field-type="dateTime" required="true">
Latest invoice date. 1900-01-01 = no upper bound. Omitted / before 1753-01-01 = error.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

## Response

The call returns the standard [response envelope](/transactional/guides/responses-and-errors). **Check `ResponseState` first**: a failed call still returns HTTP 200.

<ResponseField name="ResponseState" field-type="string" required="true">
`Success`, `Invalid` or `Error`.
</ResponseField>

<ResponseField name="ErrorCode" field-type="integer">
`0` on success, otherwise the error code. See [Errors](#errors).
</ResponseField>

<ResponseField name="Return" field-type="Payment[]">
Unknown contract, or no payment in the range: Return empty, ResponseState Success.

<Expandable title="Payment fields">

<ResponseField name="Amount" field-type="double">
The currency itself is not on the contract.
</ResponseField>

<ResponseField name="InvoiceDate" field-type="dateTime">
Date the payment is due to be invoiced. GetPaymentList filters on it.
</ResponseField>

<ResponseField name="Name" field-type="string">
The installment's name - the text that becomes the invoice line text. Tags in it are replaced when the payment is saved.
</ResponseField>

<ResponseField name="PaymentID" field-type="integer">
Integer ID of the installment. UpdatePaymentQuantity looks the payment up by this value.
</ResponseField>

<ResponseField name="ProjectID" field-type="integer">
Integer ID of the project the payment belongs to.
</ResponseField>

<ResponseField name="ProjectSubContractID" field-type="integer">
Integer ID of the contract whose payment plan holds the payment - the contractID of GetPaymentList.
</ResponseField>

<ResponseField name="Quantity" field-type="double">
Number of units invoiced by this payment. The only member UpdatePaymentQuantity writes: changing it recalculates the payment's amount from its rate and discount, and on fixed-price recurring contracts also the contract's payment-plan figures.
</ResponseField>

</Expandable>

</ResponseField>

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Error | 40001 | — | startDate or endDate omitted or before 1753-01-01. | Send real dates; for GetPaymentList use 1900-01-01 as an 'open' bound. |
