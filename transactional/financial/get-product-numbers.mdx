## How it works

Lists the account's accounting product numbers ordered by product number. legalEntityId narrows to one legal entity; 0 returns all legal entities. isActive = true returns only ACTIVE numbers and false only INACTIVE ones - there is no way to get both in one call. An unknown legal entity returns an empty list.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="legalEntityId" field-type="integer" required="true">
Integer ID of the legal entity; 0 = all legal entities.

</ResponseField>

<ResponseField name="isActive" field-type="boolean" required="true">
true = only active product numbers, false = only inactive ones.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

## Response

The call returns the standard [response envelope](/transactional/guides/responses-and-errors). **Check `ResponseState` first**: a failed call still returns HTTP 200.

<ResponseField name="ResponseState" field-type="string" required="true">
`Success`, `Invalid` or `Error`.
</ResponseField>

<ResponseField name="ErrorCode" field-type="integer">
`0` on success, otherwise the error code. See [Errors](#errors).
</ResponseField>

<ResponseField name="Return" field-type="ProductNo[]">
Response&lt;ProductNo>: Return = matching product numbers ordered by ProductNumber. No match: Return empty, ResponseState Success.

<Expandable title="ProductNo fields">

<ResponseField name="Description" field-type="string">
Free-text description; '' when not set.
</ResponseField>

<ResponseField name="IsActive" field-type="boolean">
Whether the product number is active. GetProductNumbers returns either only active or only inactive records.
</ResponseField>

<ResponseField name="LegalEntityID" field-type="integer">
Integer ID of the legal entity the product number belongs to.
</ResponseField>

<ResponseField name="Name" field-type="string">
Product name; '' when not set.
</ResponseField>

<ResponseField name="ProductNumber" field-type="string">
The product number itself, as sent to the finance system. '' when not set. The list is ordered by this value.
</ResponseField>

<ResponseField name="ProductNumberID" field-type="integer">
Integer ID of the product-number record.
</ResponseField>

<ResponseField name="UseVAT" field-type="boolean">
Whether VAT applies to lines with this product number.
</ResponseField>

<ResponseField name="VAT" field-type="double">
VAT rate of the product number, as a percentage. 0 when not set.
</ResponseField>

</Expandable>

</ResponseField>
