Returns every cost price group of the account, ordered by name.

| | |
|---|---|
| Service | Financial 1.4 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Financial/V1_4/FinancialServiceSecure.svc` |
| SOAPAction | `http://www.timelog.com/api/tlp/v1_4/FinancialService/GetEmployeeCostRates` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |

## How it works

Groups of ALL legal entities are returned together, and neither the legal entity nor the currency is on the contract, so a Rate cannot be interpreted in a multi-entity account. The REST endpoint GET /cost-price returns the same groups with legal entity and currency.
