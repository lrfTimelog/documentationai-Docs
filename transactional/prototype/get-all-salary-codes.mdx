<Callout kind="info">Rendering prototype B: one MDX page per SOAP operation.</Callout>

Returns every salary code of the tenant (active and inactive) with its salary-account posting rules.

Salary codes are the codes that time is posted under on the salary accounts: the system codes for normal working time and project time, and the tenant's supplement and paid-out codes. Factors are multipliers, not money. The list is not paged and is ordered by code, shorter codes first.

Use it to map TimeLog salary codes to the wage types of a payroll system.

## Parameters

<ParamField body="salaryCodeStatus" param-type="string" required="false">
`All`, `Active` or `Inactive`. **Not applied on V1_1:** every call returns active and inactive codes. Send `All` so the request states what the response contains, and filter on `IsActive` yourself.
</ParamField>

<ParamField body="token" param-type="SecurityToken" required="true">
The token returned by the Security service's GetToken. Send its three fields back unchanged.
</ParamField>

## Response

`GetAllSalaryCodesResponse` / `GetAllSalaryCodesResult`. Errors are also returned with HTTP 200: check `ResponseState` first, then `ErrorCode`.

<ResponseField name="ResponseState" field-type="string" required="true">
`Success`, `Invalid` or `Error`.
</ResponseField>

<ResponseField name="ErrorCode" field-type="integer">
Error code when `ResponseState` is not `Success`.
</ResponseField>

<ResponseField name="Return" field-type="Salary[]">
The salary codes. Empty when the tenant has none (`ResponseState` is then `Success`) and on error.
</ResponseField>

## Errors

| ErrorCode | Meaning | What to do |
|---|---|---|
| 40001 | The `token` element was omitted or sent as nil. | Pass the token from GetToken. |
| 20003 | The token does not match this site: it was issued by another site, a field was edited, or `Expires` was not sent back exactly as received. | Send the token's three fields back unchanged. |
| 20004 | The token has expired. Tokens live 12 hours. | Call GetToken again and retry. |
| 20008 | The Transactional API is not enabled for this site. | Ask your TimeLog administrator. Retrying does not help. |
| 20009 | The call was not made over HTTPS. | Call the `…ServiceSecure.svc` URL over HTTPS. |
