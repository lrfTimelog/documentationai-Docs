<Callout kind="info">Rendering prototype B: one MDX page per SOAP operation.</Callout>

Returns the tenant's allowance (per-diem) legislations (ID and name).

The legislations are the country rule sets used for employees' travel allowances. Only the ID and name are returned, ordered by ID; the country code, legislation type and allowance rates are not. The list is not paged.

Use it to pick the allowance legislation ID for employees created from an HR system.

| | |
|---|---|
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/Salary/V1_1/SalaryServiceSecure.svc` |
| SOAPAction | `http://www.timelog.com/api/tlp/v1_1/SalaryService/GetAllowances` |
| Content-Type | `text/xml; charset=utf-8` (SOAP 1.1) |
| WSDL | `…/SalaryServiceSecure.svc?wsdl` |
| Safe to retry | Yes (read-only) |

## Parameters

<ParamField body="token" param-type="SecurityToken" required="true">
The token returned by the Security service's GetToken. Send its three fields back unchanged.
</ParamField>

## Response

`GetAllowancesResponse` / `GetAllowancesResult`. Errors are also returned with HTTP 200: check `ResponseState` first, then `ErrorCode`.

<ResponseField name="ResponseState" field-type="string" required="true">
`Success`, `Invalid` or `Error`.
</ResponseField>

<ResponseField name="ErrorCode" field-type="integer">
Error code when `ResponseState` is not `Success`.
</ResponseField>

<ResponseField name="Return" field-type="Allowance[]">
The legislations. Empty when the tenant has none (`ResponseState` is then `Success`) and on error.
</ResponseField>

<ResponseField name="Return[].Id" field-type="integer">
Allowance legislation ID — the value for an employee's allowance legislation.
</ResponseField>

<ResponseField name="Return[].Name" field-type="string">
Description of the legislation.
</ResponseField>

## Errors

| ErrorCode | Meaning | What to do |
|---|---|---|
| 40001 | The `token` element was omitted or sent as nil. | Pass the token from GetToken. |
| 20003 | The token does not match this site: it was issued by another site, a field was edited, or `Expires` was not sent back exactly as received. | Send the token's three fields back unchanged. |
| 20004 | The token has expired. Tokens live 12 hours. | Call GetToken again and retry. |
| 20008 | The Transactional API is not enabled for this site. | Ask your TimeLog administrator. Retrying does not help. |
| 20009 | The call was not made over HTTPS. | Call the `…ServiceSecure.svc` URL over HTTPS. |
