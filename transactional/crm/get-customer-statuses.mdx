Returns the account's active customer statuses with their group flags.

| | |
|---|---|
| Service | CRM 1.4 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/CRM/V1_4/CRMServiceSecure.svc` |
| SOAPAction | `http://api.timelog.com/services/crm/1_4/ICRMService/GetCustomerStatuses` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |

## How it works

The value set for a customer's status: every ACTIVE, non-system customer status configured on the account, with its integer ID, name and Type flags. Inactive statuses and system statuses are left out - unlike REST GET /v1/customerstatus, which also returns inactive ones.

## Response

The call returns the standard [response envelope](/transactional/guides/responses-and-errors). **Check `ResponseState` first**: a failed call still returns HTTP 200.

<ResponseField name="ResponseState" field-type="string" required="true">
`Success`, `Invalid` or `Error`.
</ResponseField>

<ResponseField name="ErrorCode" field-type="integer">
`0` on success, otherwise the error code. See [Errors](#errors).
</ResponseField>

<ResponseField name="Return" field-type="CustomerStatus[]">
Response&lt;CustomerStatus>: all active non-system statuses, unpaged. No 'Successfully called' message. ResponseState Success with an empty Return when no active status exists.

<Expandable title="CustomerStatus fields">

<ResponseField name="ID" field-type="integer">
Integer ID of the status - the value used as a customer's status.
</ResponseField>

<ResponseField name="Name" field-type="string">
Display name of the status, as configured by the account.
</ResponseField>

<ResponseField name="Type" field-type="string">
Which customer groups the status belongs to. Allowed values: `None`, `IsShownInCustomers`, `IsShownInSuppliers`, `IsShownInLeads`, `IsMultiCustomerProjects`, `All`.
</ResponseField>

</Expandable>

</ResponseField>
