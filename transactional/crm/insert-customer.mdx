Creates a customer and returns it.

| | |
|---|---|
| Service | CRM 1.4 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/CRM/V1_4/CRMServiceSecure.svc` |
| SOAPAction | `http://api.timelog.com/services/crm/1_4/ICRMService/InsertCustomer` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Permissions | Customer privilege 'all customers': may create any customer. |
| Changes data | Yes |
| Safe to retry | Depends on the call |

## How it works

Creates a customer from the Customer object. Name, Address.Country, Status and Currency are required; Industry and KAM must exist when sent. Customer.ID is ignored. Leave No empty to get the next number of the account's customer number series. On success Return[0] is the customer as built from the request plus its new ID and ResponseState is Success. Validation and privilege failures come back as ResponseState Invalid with the reason in Messages and the customer you sent in Return[0] - check ResponseState, not Return. Retry safety: supply your own GUID.

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Invalid | 10002 | \{field\}, was null or empty | 'FirstName, was null or empty', 'Country, was null or empty'). | Send the named value. |
| Invalid | 30017 | Unknown Country ISO Code: \{code\} | Address.Country unknown. | — |
| Invalid | 30018 | Unknown Customer Status ID: \{status\} | Customer.Status is not the name of an existing customer status of the account. | Send the exact Name of a status from GetCustomerStatuses. |
| Invalid | 30015 | Unknown employee Initials: '\{initials\}'. | KAM initials unknown. | — |
| Invalid | 30019 | Unknown Industry: \{industry\} | Customer.Industry is not the name of an existing industry. | Send an existing industry name or leave Industry empty. |
| Invalid | 30020 | Unknown Currency Abbreviation: \{abbreviation\} | Customer.Currency is not the abbreviation of a currency of the account. | Send an existing currency abbreviation. |
| Invalid | 30169 | Customer number is already in use | — | Send a different number, or leave No empty to use the customer number series. |
| Invalid | 20012 | User: \{initials\}, has Insufficient Access. Missing privilege was: \{role\} | — | — |
| Invalid | 10001 | Create of Customer failed! | — | For updates, read the customer first and send its ID; otherwise retry later or report. |
