description: "CRM service 1.4: Returns the customers whose name is exactly the given name - or every customer when no name is sent - a page at a time."
---

| | |
|---|---|
| Service | CRM 1.4 |
| Endpoint | `POST https://app{server-number}.timelog.com/{account}/WebServices/CRM/V1_4/CRMServiceSecure.svc` |
| SOAPAction | `http://api.timelog.com/services/crm/1_4/ICRMService/GetCustomersByNamePaged` |
| Content-Type | `text/xml; charset=utf-8` |
| Authentication | A token from [GetToken](/transactional/guides/authentication) |
| Changes data | No |
| Safe to retry | Yes |
| Paging | Yes, up to 500 per page |

## How it works

Each customer comes with its active contacts; custom fields and external keys are filled when loadCustomFields / loadExternalKeys are true.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="name" field-type="string">
**Optional.** An empty string matches only customers with an empty name.

</ResponseField>

<ResponseField name="loadCustomFields" field-type="boolean">
**Optional.** Default `false`. Fill CustomFields of each customer.

</ResponseField>

<ResponseField name="loadExternalKeys" field-type="boolean">
**Optional.** Default `false`. Fill ExternalKeys of each customer.

</ResponseField>

<ResponseField name="page" field-type="integer" required="true">
1-based page number.

</ResponseField>

<ResponseField name="pageSize" field-type="integer" required="true">
Items per page, capped at 500; must be > 0.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>
