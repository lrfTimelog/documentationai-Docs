## How it works

Reads a single contact by the contact's GUID. The contact comes back as Return[0] of the Response envelope. Set loadCustomFields / loadExternalKeys to also fill the contact's custom fields and its external-system keys; otherwise those lists are empty and IsCustomFieldsLoaded / IsExternalKeysLoaded are false. An unknown GUID is an ERROR, not an empty result: ResponseState Error, ErrorCode 40001 and a data-layer message. Inactive contacts are returned like active ones.

## Parameters

Each parameter has one label: **Required**, **Conditional** (required depending on other values) or **Optional**.
Send them in the order shown.

<ResponseField name="guid" field-type="guid" required="true">
GUID of the contact.

</ResponseField>

<ResponseField name="loadCustomFields" field-type="boolean">
**Optional.** Default `false`. true = fill CustomFields and set IsCustomFieldsLoaded.

</ResponseField>

<ResponseField name="loadExternalKeys" field-type="boolean">
**Optional.** Default `false`. true = fill ExternalKeys and set IsExternalKeysLoaded.

</ResponseField>

<ResponseField name="token" field-type="SecurityToken" required="true">
The token from [GetToken](/transactional/guides/authentication): `Initials`, `Expires` and `Hash`, sent back unchanged.

</ResponseField>

`Success`, `Invalid` or `Error`.
</ResponseField>

<ResponseField name="ErrorCode" field-type="integer">
`0` on success, otherwise the error code. See [Errors](#errors).
</ResponseField>

<ResponseField name="Return" field-type="Contact[]">
Response&lt;Contact>: Return holds exactly one Contact. No 'Successfully called' message is added; Messages holds only the call duration. Never empty on success: an unknown GUID is ResponseState Error.

## Errors

All errors come back with **HTTP 200**: check `ResponseState`, `ErrorCode` and `Messages`. The errors every operation can return (expired or invalid token, API not enabled, HTTPS required, general errors) are listed once in [Responses and errors](/transactional/guides/responses-and-errors#error-codes).

Errors specific to this operation:

| ResponseState | ErrorCode | Message | What it means | What to do |
|---|---|---|---|---|
| Error | 40001 | Error during call on TimeLog.API, Message 'Unable to retrieve result from … GUID\{guid\}' | No contact has this GUID. | Check the GUID; treat this message as 'not found'. |
